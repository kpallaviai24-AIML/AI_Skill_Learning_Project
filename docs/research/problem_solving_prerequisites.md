# Problem-Solving Skill Prerequisite Research

## Objective
Identify evidence-supported learning dependencies between problem-solving skills.

## Candidate skills
1. Identify and define a problem
2. Gather relevant information
3. Organise and analyse information
4. Identify possible causes
5. Generate alternative solutions
6. Evaluate possible solutions
7. Select an appropriate solution
8. Implement a solution
9. Evaluate the outcome

## Source 1: American Society for Quality (ASQ)

Title: Problem Solving

URL: https://asq.org/quality-resources/problem-solving

### Findings
ASQ describes a problem-solving process that includes:
- Define the problem.
- Diagnose the root cause.
- Identify and implement a solution.
- Sustain the results.

The resource discusses collecting and analysing data while defining the problem, identifying root causes, generating alternative solutions, evaluating alternatives, and monitoring outcomes.

### Evidence interpretation
This source supports a structured problem-solving workflow. It does not establish that every stage is a universal learning prerequisite for the next stage.

## Source 2: U.S. Department of Education

Title: Approaches to Root Cause Analysis

URL: https://www.ed.gov/teaching-and-administration/lead-and-manage-my-school/state-support-network/ssn-resources/approaches-to-root-cause-analysis

### Findings
The resource identifies common root-cause-analysis activities:
- Define the problem and gather relevant data.
- Identify potential causes and determine root causes.
- Identify evidence-based strategies to address the problem.

It also notes that there is no single method for conducting root cause analysis.

### Evidence interpretation
This source supports the relationship between problem definition, evidence gathering, cause analysis, and selecting strategies as parts of an investigation process. It does not prove universal learning prerequisites.

## Source 3: ASQ Root Cause Analysis

Title: What is Root Cause Analysis?

URL: https://asq.org/quality-resources/root-cause-analysis

### Findings
ASQ describes root cause analysis as a collection of approaches, tools, and techniques for uncovering causes of problems.

### Evidence interpretation
This supports the importance of cause analysis as a problem-solving competency. It does not establish a universal prerequisite sequence.

## Preliminary conclusion
The sources support a problem-solving workflow, but workflow order alone is insufficient evidence for a learning prerequisite graph.

Do not approve prerequisite edges based only on these process descriptions.

## Evidence requirements
- Record the exact source and relevant section.
- Distinguish learning prerequisites from workflow order.
- Keep unverified relationships as needs_review.
- Do not invent or automatically approve dependencies.
